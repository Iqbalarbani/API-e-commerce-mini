# Mini Shop API

E-Commerce REST API built with **FastAPI**, **SQLAlchemy 2.x**, **Alembic**, **Pydantic v2**, and **PostgreSQL**, containerized with **Docker Compose**.

## Tech Stack
- **Framework**: FastAPI (Async, Type-hinted)
- **Database**: PostgreSQL 16 via SQLAlchemy 2.x ORM
- **Migrations**: Alembic
- **Validation**: Pydantic v2
- **Containerization**: Docker & Docker Compose
