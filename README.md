# Mini Shop API

A production-style e-commerce REST API built with **FastAPI**, **SQLAlchemy 2.x**, **Alembic**, and **PostgreSQL 16**.

> Detailed setup instructions, API documentation, architecture overview, and ERD will be completed in the final documentation stage.

## Quick Start (Stage 1)

```bash
cp .env.example .env
docker compose up --build
```

Check health status:

```bash
curl http://localhost:8000/health
```
